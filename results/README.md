# Results and reproduction

Only measurements generated by `app/benchmark.mjs` in this worktree belong to this revision. No main-repository testbed data are imported. The protocol is frozen in PROTOCOL.md; preparation failures are retained in INCIDENTS.md.

## Prerequisites

macOS with Docker Desktop running Linux containers, Node.js 22, Python 3.11+, native Pandoc, Tectonic, git and caffeinate. Docker must support NET_ADMIN/tc in the dedicated client. A main-research `harness.mjs` process blocks measurement. Other platforms need an equivalent awake command before measurement, not a silently ignored missing tool.

From the worktree root:

```sh
python3 -m venv .venv
.venv/bin/pip install -r results/requirements.txt
UNI_PYTHON="$PWD/.venv/bin/python" ./app/run-benchmark
```

That one benchmark command builds production images, starts project unibench, loads the original synthetic dump, checks every product against the independent SQL oracle, warms all cache/render configurations, runs the randomized 720-run sweep, collects a separate 24-pair process-startup companion, and analyzes both. The first image/tool download needs internet access. Reuse of a completed sweep resumes/skips complete run IDs, so this command does not silently overwrite existing evidence. For a genuinely fresh replication, archive the entire results/raw directory, create a new empty one and use a new clone/own volumes or clear only this project's caches after preserving evidence. Never delete the supplied logs to reproduce tables: use the analysis-only command below.

For a fresh measurement sweep in this same worktree after preserving the delivered state:

```sh
docker compose -p unibench -f app/docker-compose.yml down
UNI_ARCHIVE="results/raw-delivered-$(date -u +%Y%m%dT%H%M%SZ)"
mv results/raw "$UNI_ARCHIVE"
mkdir results/raw
UNI_PYTHON="$PWD/.venv/bin/python" ./app/run-benchmark
```

`down` removes only this project's containers/network, clearing the Next writable-layer cache and Redis instance; it preserves the named synthetic DB volume. Do not use a global prune or any cachebed command. The archive preserves the old raw evidence. This changes the local result files and should be done in a separate working copy if the delivered manuscript must remain byte-for-byte intact.

Smoke only (eight cells at zero added delay): `./app/run-benchmark smoke`. Smoke does not generate publication results. Audit it using `UNI_PYTHON="$PWD/.venv/bin/python" results/analyze --smoke`.

Analysis only, no Docker/measurement/network needed:

```sh
UNI_PYTHON="$PWD/.venv/bin/python" results/analyze
PANDOC=/path/to/pandoc TECTONIC=/path/to/tectonic .venv/bin/python manuscript/build.py
```

Native Pandoc 3.12.1 creates both DOCX and generic-article LaTeX. Install the ARM macOS build on Apple Silicon; do not rely on pypandoc_binary 1.17, whose tested ARM wheel contained an x86 executable. Tectonic 0.17.0 compiles the PDF and needs internet on first use to fetch TeX packages; macOS Times New Roman fonts must be installed. The manuscript Word reference template sets SUJ formatting; the build checks abstract and source word limits. `references.json` is the Pandoc CSL bibliography; `references.bib` contains the same verified sources for LaTeX users.

## Raw evidence

- `raw/primary-manifest.json`: prerecorded randomized cell order, seed and replication count.
- `raw/runs.jsonl`: completed run metadata, page sequence, timing bounds, Chromium version and all TCP samples.
- `raw/browser.jsonl`: warm-up, smoke and primary observations with phase, session, action, DOM/frame/origin times, requested product and opaque response ID.
- `raw/api.jsonl`: one event for each actual API response; Redis get/set outcome, SQL duration, service duration and bytes.
- `raw/batches.jsonl`: UTC batch boundaries, exact own-container measurement command, before/after empty pgrep evidence and exit status; watchdog also checks every 250 ms.
- `raw/failures.jsonl`, when present: failed browser runs, retained rather than silently discarded.
- `raw/sql-check.txt`: full-load relation counts, all-product oracle and legacy mismatch count.
- `raw/environment.json`, `build.txt`, `startup.txt`, console logs: software/hardware and preparation provenance.

`derived/` contains every cell summary, independent-run aggregates, strict cache audit, early/late drift check, raw hashes and manuscript substitutions. `manuscript/figures/` contains both PDF vector figures and 300-dpi PNGs. Every empirical manuscript value is generated from raw evidence by analyze.py; study-design constants are documented in PROTOCOL.md.

Cache audit fails on unexpected API counts, an impossible cached response, missing creation events, wrong product/page, negative elapsed time, an unexpected Redis outcome, missing SQL on a miss or SQL on a hit, or browser/API errors. No stale timing metadata are used to assert a new request hit. Run-level bootstrap resampling uses seed 20261020 and 10,000 draws; no individual-click independence is assumed.

See HANDOVER.md for measured runtime, exact artifact paths, main-harness safety and the final five spot checks.

Interrupted collection is recovered by `app/complete-benchmark.py`: it retains every guard failure, waits for two clear checks, uses fresh primary retry namespaces, and restarts/repeats an interrupted startup pair in full. The guard is not filtered to ignore shell matches. Successful cells are never selected by observed latency. See INCIDENTS.md and derived/exclusions.json for the actual exclusions.
